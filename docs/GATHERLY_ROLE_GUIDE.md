# Gatherly Role Guide

## Super Admin
Purpose: Owns the fellowship account and manages setup.
Dashboard: Full fellowship dashboard.
Allowed modules: Dashboard, Members, Units, Attendance, Events, Finance, Budgets, Approvals, Reports, Settings, Profile, Insights.
Main responsibilities: Setup fellowship profile, add leaders, manage members, oversee finance and approvals.
Cannot perform: No major frontend module is intentionally blocked.

## Fellowship Admin
Purpose: Helps administer the fellowship.
Dashboard: Management dashboard.
Allowed modules: Dashboard, Members, Units, Attendance, Events, Budgets, Approvals, Reports, Settings, Profile, Insights.
Main responsibilities: Members, units, reports, approvals support, setup assistance.
Cannot perform: Finance page is not available in the current protected route matrix.

## Pastor
Purpose: Leadership oversight.
Dashboard: Leadership-oriented dashboard.
Allowed modules: Dashboard, Members, Units, Attendance, Events, Finance, Budgets, Approvals, Reports, Settings, Profile, Insights.
Main responsibilities: Oversight of people, ministry health, approvals, and finances.
Cannot perform: Backend may still restrict some actions.

## President
Purpose: Final approval authority.
Dashboard: Approval-focused dashboard.
Allowed modules: Dashboard, Attendance, Events, Budgets, Approvals, Settings, Profile.
Main responsibilities: Review approved/forwarded budget requests and approve or decline.
Cannot perform: Members, Units, Finance, Reports, and Insights in the current frontend matrix.

## General Secretary
Purpose: Review and forward budget requests.
Dashboard: Review-focused dashboard.
Allowed modules: Dashboard, Attendance, Events, Budgets, Approvals, Settings, Profile.
Main responsibilities: Review submitted requests, add comments, forward to President.
Cannot perform: Members, Units, Finance, Reports, and Insights in the current frontend matrix.

## Financial Secretary / Finance Officer
Purpose: Records income and expenses.
Dashboard: Finance-focused dashboard.
Allowed modules: Dashboard, Attendance, Events, Finance, Budgets, Settings, Profile.
Main responsibilities: Maintain ledger accounts, record income, record expenses, watch approved-budget notifications.
Cannot perform: Members, Units, Approvals, Reports, and Insights in the current frontend matrix.

## Unit Head
Purpose: Leads a unit or department.
Dashboard: Unit-focused dashboard where backend data is available.
Allowed modules: Dashboard, Attendance, Events, Budgets, Settings, Profile.
Main responsibilities: Create and submit budget requests, support attendance/events where applicable.
Cannot perform: Members, Units management, Finance, Approvals, Reports, and Insights in the current frontend matrix.

## Department Leader
Purpose: Supports unit-level leadership.
Dashboard: Unit-focused dashboard where backend data is available.
Allowed modules: Dashboard, Attendance, Events, Budgets, Settings, Profile.
Main responsibilities: Unit activities and budget requests where permitted.
Cannot perform: Members, Units management, Finance, Approvals, Reports, and Insights in the current frontend matrix.

## Member
Purpose: Basic fellowship member access.
Dashboard: Member dashboard.
Allowed modules: Dashboard, Attendance, Events, Budgets, Settings, Profile.
Main responsibilities: View personal dashboard, events, attendance-related information, and profile.
Cannot perform: Members, Units, Finance, Approvals, Reports, and Insights in the current frontend matrix.
