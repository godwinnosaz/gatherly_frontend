# Gatherly Quick Start

## 1. Register Fellowship
Open Gatherly, choose Create Account, enter fellowship name, email, password, and confirm password. The registering user becomes Super Admin.

Screenshot: ![Registration](./user-guide/screenshots/02-signup.png)

## 2. Complete Fellowship Profile
Open Settings, then Fellowship Profile. Add organization details, contact information, branding, and public profile details where available.

Screenshot: ![Fellowship profile](./user-guide/screenshots/04-fellowship-profile.png)

## 3. Create Departments
Open Units, create Choir, Media, Ushering, Welfare, Prayer Unit, or your own fellowship units.

Screenshot: ![Units](./user-guide/screenshots/05-units-list.png)

## 4. Add Executive Leaders
Open Members, Add Member, turn on Grant Login Access, choose the correct role, and send or copy the invite link.

Screenshot: ![Add Member](./user-guide/screenshots/08-add-member-modal.png)

## 5. Share Invite Links
If email sending fails, copy the invite link and send it safely to the leader or member.

Screenshot: ![Invite result](./user-guide/screenshots/10-member-invite-result.png)

## 6. Add or Import Members
Use Add Member for one person. Use Import for CSV batches with `first_name`, `last_name`, `email`, `phone`, `status`, `grant_login_access`, `role`, and `department`.

Screenshot: ![CSV import](./user-guide/screenshots/11-csv-import.png)

## 7. Create Finance Account
Open Finances and create an internal ledger account. This is for Gatherly tracking, not a bank account.

Screenshot: ![Finance](./user-guide/screenshots/13-finance-overview.png)

## 8. Record Opening Income
Click Add Income, select account and category, enter amount/date/description/reference, then submit.

Screenshot: ![Income](./user-guide/screenshots/14-finance-income-modal.png)

## 9. Create First Event
Open Events, create an event with title, type, date, time, location, and description.

Screenshot: ![Events](./user-guide/screenshots/19-events.png)

## 10. Create First Attendance Session
Open Attendance, create a session, mark members, and save.

Screenshot: ![Attendance](./user-guide/screenshots/18-attendance.png)

## 11. Test Budget Approval Workflow
Create a budget request, submit it, review as General Secretary, approve as President, then let the Financial Secretary record finance activity if required.

Screenshot: ![Approvals](./user-guide/screenshots/17-approvals-queue.png)
